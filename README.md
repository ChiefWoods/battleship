## Getting Started

### Prerequisites

Update your Bun toolkit to the latest version.

```bash
bun upgrade
```

### Setup

1. Clone the repository

```bash
git clone https://github.com/ChiefWoods/battleship.git
```

2. Install all dependencies

```bash
bun install
```

3. Start development server

```bash
bun run dev
```

4. Build project

```bash
bun run build
```

5. Preview build

```bash
bun run preview
```

6. Test project

```bash
bun run test
```
